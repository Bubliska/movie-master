VERSION 0.4.3 · BETA

A few details.

Mac

Apple Silicon, macOS 15 or later. DOSBox-X is included. Open the DMG and drag the app to Applications. This personal beta is ad-hoc signed and isn't Apple-notarized. No Intel Mac build is included.

DOS & Windows

The ZIP includes DOS, WIN32 and WIN64 builds. Windows 10–11: extract the entire ZIP and run BASLAT.BAT. DOS: 386+, VGA and extended memory; 32 MB recommended. Keep FONT.TTF and CWSDPMI.EXE beside WRITER.EXE. Windows builds are compiled but haven't been tested on a live Windows machine.

First Save: F10 → choose a folder → F5 Save Here → enter a name. Save As and every export let you choose a location again.
