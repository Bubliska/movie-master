VERSION 0.4.4 · BETA

A few details.

Mac

Apple Silicon, macOS 15 or later. DOSBox-X is included. Open the DMG and drag the app to Applications. This beta is ad-hoc signed and isn't Apple-notarized, so macOS may block its first launch. Read the Mac installation instructions. No Intel Mac build is included.

Keyboard layouts

US, UK, Dvorak, Turkish Q/F, Spanish, French AZERTY, German QWERTZ, Italian, Portuguese and Brazilian Portuguese. Choose a layout in Settings. The current text set supports Latin scripts; Cyrillic, Arabic and CJK text are not yet supported.

DOS & Windows

The ZIP includes DOS, WIN32 and WIN64 builds. Windows 10–11: extract the entire ZIP and run START.BAT. DOS: 386+, VGA and extended memory; 32 MB recommended. Keep FONT.TTF and CWSDPMI.EXE beside MOVIEMST.EXE. Windows builds are compiled but haven't been tested on a live Windows machine.

Mac: File → Import Fountain opens the macOS file chooser at Desktop, including Unicode filenames.

First Save: F10 → choose a folder → F5 Save Here → enter a name. Save As and every export let you choose a location again.
